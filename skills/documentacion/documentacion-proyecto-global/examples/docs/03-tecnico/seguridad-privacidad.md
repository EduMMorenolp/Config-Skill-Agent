# Seguridad y Privacidad

| Aspecto | Definición |
|---|---|
| Autenticación | Sesion con token firmado y expiracion corta sobre la autenticacion corporativa |
| Autorización | Roles de operador y supervisor; el estado solo lo cambia un supervisor |
| Privacidad de datos | Datos de cliente minimos y sin informacion sensible fuera de la operacion |
| Retención de datos | Los pedidos se conservan mientras el comercio tenga cuenta activa |
| Jurisdicción | Segun la jurisdiccion donde opere el proyecto |
