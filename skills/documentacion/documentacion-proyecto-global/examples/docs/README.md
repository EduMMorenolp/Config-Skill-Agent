## Glosario

- **EDT / WBS:** estructura de desglose del trabajo.
- **ERS:** especificacion de requisitos de software (RF, RNF y criterios de aceptacion).
- **RACI:** responsable, aprueba, consultado e informado por actividad.
- **ADR:** registro de una decision de arquitectura con su contexto y consecuencias.
- **MVP:** version minima con valor real para validar con usuarios.
