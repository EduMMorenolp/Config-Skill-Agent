# Vision de Producto

## Visión

Que cualquier comercio cargue y siga sus pedidos desde un solo lugar, sin planillas y con el estado siempre a la vista.

## Propuesta de valor

Menos errores de carga y trazabilidad completa del pedido, con una interfaz que el operador aprende en una sola sesion.

## Lean Canvas

| Bloque | Contenido |
|---|---|
| Problema | Carga manual en planillas, estados perdidos y demoras en la confirmacion |
| Segmentos | Comercios minoristas con operacion diaria de pedidos |
| Propuesta única | Pedidos centralizados, auditados y visibles en tiempo real |
| Canales | Venta directa y referidos de comercios existentes |
| Ingresos | Suscripcion mensual por comercio |
| Costos | Desarrollo, infraestructura y soporte |
| Métricas clave | Pedidos por semana, tiempo de carga y tasa de error |
| Ventaja injusta | Integracion con el proceso operativo ya conocido por los comercios |
